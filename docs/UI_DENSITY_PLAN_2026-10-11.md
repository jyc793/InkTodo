# 墨待全局排版密度方案（先设计，后改代码）

基准：Redmi K70 至尊版短边约 375dp；同时检查 320dp 窄屏、字体放大及平板横屏。不更换山水背景、四色意象或锦鲤动效。

## 改动原则

1. 触控目标始终至少 48dp；压缩的是装饰性空白和重复容器，不缩小实际点按区域。
2. 正文保持 14–16sp，说明文字至少 12sp。日历标题预览虽小，仍使用 12sp、单行省略和完整无障碍朗读。
3. 一级标题由 36sp 收至 28sp，意象章由 48dp 收至 40dp；保留场景差异，但页首高度约减少 20dp。
4. 手机统一 16dp 页面边距、8–12dp 卡片内边距、8dp 常规间距；圆角保留水墨琉璃的柔和感，从大面积 26dp 收至约 18–20dp。
5. 列表保留任务标题、时间和一行备注；“完成/恢复”和“删除”保持独立可见操作与原有确认，不通过隐藏功能换空间。

## 页面布局

| 页面 | 当前空间瓶颈 | 目标 |
|---|---|---|
| 待办/已完成 | 大页首、卡片完成与删除分占两层、备注最多两行 | 紧凑页首；任务信息区与竖排操作区并列；备注一行省略，点开看完整内容；每卡高度约 96–112dp |
| 新建/编辑 | 日期、重复、提醒分多张大卡，卡间 16dp；说明占多行 | 分组仍清晰但间隔 8–12dp；日期/时间并列；简化重复规则说明；保存按钮固定清楚且易点 |
| 日历 | 仅墨点、不知多少任务；格子高度不足摘要 | 每格上行日期及小计数，下行 12sp 摘要省略；单元至少 48dp 可点；所选日下方完整任务仍保留 |
| 番茄钟 | 计时环占短边 76%，上下各 24dp；选择器和控制区需频繁滚动 | 环占短边约 68–70%；缩小上下装饰空白；控制区保留 48dp 按钮和专注入口 |
| 设置 | 每卡 24dp 内边距、卡间 16dp；已开启项与待处理项同等视觉高度 | 卡内边距 12–16dp；状态与按钮同行优先；说明限可读行数，不删权限状态或入口 |
| 完全专注/正式确认 | 需要视觉安静与误触防护 | 不为密度牺牲中心倒计时或确认按钮；仅随共享字号/圆角同步检查 |

## 验收标准

- 375dp 手机上主页首屏至少多露出一行任务内容；标题、主要按钮不截断或溢出。
- 日历 42 格全可点，任务数及摘要不盖住日期；中文与动态字体放大时允许页面滚动。
- 320dp 宽度无水平越界；所有危险操作仍需要原有确认。
- 浅/深色文字保持足够对比，Widget 本轮不改视觉资源。
